# AI Tools Exploration

## Overview
This folder contains **two AI-based exploration files** as part of the AI course:  
1. **Video** – A short video summarizing the course, lab tasks, and algorithms learned.  
2. **Presentation Slide** – A 14 slide presentation summarizing the theory, algorithms, and AI games.

These tasks demonstrate how AI tools can be used to **create educational content** combining theory and practical lab exercises.


## Video Creation
- **Tool Used:** **ai.invideo.io** free plan  
- **Duration:** 2:20  
- **Content Covered:**  
  - Most of the topics that we have covered before our mid exam. 

### Steps to Create the Video
First of all, I researched a bit about the available AI video-making tools. My research was mostly based on ChatGPT. So after getting suggestions from GPT, I tried some tools like Lumen5, steve.ai, Animaker, Invideo, etc. Among them, some are credit-based, paid, and I don't feel comfortable with them. But Invideo was very flexible and comfortable, so I used it.
I take the script from DeepSeek. 

steps that  I have used
1. Open the AI video tool (ai.invideo.io).
2. Log in with a Gmail
3. Select **“Text-to-Video”** 
4. Write a **in details script** covering:
   - AI course objectives  
   - Lab tasks and algorithms implemented  
   - Games developed  
5. Use ** stock slides, images, and screenshots** of algorithms/games.  
6. Customize **transitions, background music, and timing** to fit the time limit.  
7. Export the video as `AI_Video.mp4`.  

**Reference / Tutorials Followed:**  
- [Canva Video Guide](https://www.canva.com/learn/how-to-make-a-video/)  


## Presentation Slides Creation
- **Tool Used:** **GAMMA** (free plan)  
- **Slides:** 14 slides summarizing the AI course  

### Steps to Create the Presentation

The process is the same as AI video. I tried some tools like Beautifull.ai, Tome.app, etc., which were suggested by ChatGPT. But among them, I find Gamma best. They provide a built-in template which makes the work way easier. This time, I also made the script from DeepSeek and made the presentation

Steps that I have followed.
1. Open Gamma and select **Text to presentation**.  
2. Include slides covering:
   - Introduction & purpose of the AI course  
   - Algorithms implemented (with short explanations and images)  
   - AI games developed (with screenshots)  
   - Learnings from the course  
   - Supervisor/Instructor information  
3. Add **visuals, icons** for clarity.  
4. Download the presentation as `AI_Presentation_com.pdf`.  

**Reference / Tutorials Followed:**  
- [Canva Tutorials for Students](https://www.canva.com/learn/presentations/)
